# 📦 قاعدة بيانات كافيهات ومطاعم ومشاريع الخبر والظهران لشركات التغليف (348 مشروعاً)

دليل ميداني وقاعدة بيانات كبرى تضم **348 كافيه، مطعم، مخبز، ومحل شاي** في **مدينة الخبر والظهران وضواحيها**، مصممة خصيصاً لشركات التغليف والكرتون والطباعة لمساعدة مناديب المبيعات على تنفيذ زيارات بيع ميدانية منظمة حسب المسافة وتوزيع الجولات.

---

## 🎯 تصنيف المشاريع الـ 348 واحتياجات التغليف المستهدفة لكل قطاع:

1. **كافيهات ومحامص القهوة المختصة (99 مشروعاً):**
   * **المنتجات المستهدفة للبيع:** أكواب ورقية دبل وسنجل وول (4، 7، 8، 12، 16 أونص)، كاسات بلاستيك شفافة باردة PET، فلاتر V60 وكيمكس ومكائن التقطير، أكياس بن كرافت مع صمام وسحاب، أغطية كاسات، حوامل كاسات كرتون (2-cup / 4-cup)، أكياس كرافت تيك أواي، ستيكرات لوجو.
2. **مطاعم البرجر والوجبات السريعة (76 مشروعاً):**
   * **المنتجات المستهدفة للبيع:** بوكسات برجر كرتون مقواة، علب وبوكسات بطاطس، ورق ساندوتش مقاوم للزيوت والحرارة، علب صوصات بلاستيكية بأغطية محكمة (1، 2، 3 أونص)، أكياس ورقية بمقبض شريطي، أطقم شوك وملاعق ومناديل مبللة.
3. **مطاعم ومأكولات متنوعة ومشويات وشاورما (131 مشروعاً):**
   * **المنتجات المستهدفة للبيع:** بوكسات وجبات كرتونية، بوكسات شاورما عربي، صحون ألمنيوم وقصدير، علب ميكروويف بلاستيكية بغطاء محكم، أكياس توصيل ورقية متينة، سفر طعام ورقية وبلاستيكية.
4. **مخابز وحلويات وكيك ومحلات شوكولاتة (24 مشروعاً):**
   * **المنتجات المستهدفة للبيع:** بوكسات كيك بنافذة شفافة مقاسات متعددة، علب حلى وتارت وتشيز كيك، قواعد كيك كرتونية ذهبية وفضية، أكياس بيكري ورقية للكرواسون، أشرطة تغليف ستان مطبوعة.
5. **مطاعم بيتزا وفطائر ومعجنات (10 مشاريع):**
   * **المنتجات المستهدفة للبيع:** كراتين بيتزا بمقاسات (9، 11، 13، 15 إنش)، فواصل بيتزا بلاستيكية ثلاثية، بوكسات فطاير كرتونية، أكياس حرارية للتوصيل.
6. **كافيهات ومحلات شاي وكرك ومشروبات بوبا (6 مشاريع):**
   * **المنتجات المستهدفة للبيع:** أكواب شاي كرك ورقية سميكة وعازلة، بوكسات وسخانات شاي جمعات (2 و 3 لتر)، كاسات بوبا مع غشاء تغليف حراري (Sealing Film)، مصاصات بوبا عريضة.
7. **محلات آيسكريم وعصائر (2 مشاريع):**
   * **المنتجات المستهدفة للبيع:** كاسات آيسكريم كرتونية مطبوعة، قوارير عصير بلاستيكية، أغطية قبة، ملاعق ملونة.

## 🛠️ أدوات المندوب الميداني في تطبيق `index.html`:
1. **📍 زر تحديد الموقع الحي (GPS):** يحسب المسافة الحقيقية فورا من موقع المندوب ويرتب كل الـ 348 مشروعاً من الأقرب إلى الأبعد.
2. **🧭 اختيار نقطة الانطلاق:** حساب المسافات مسبقاً من (المطل، الحزام، باتيو، البندرية، الراكة، إثراء، التحلية).
3. **توجيه ملاحة مباشر بخرائط جوجل:** فتح GPS بنقرة واحدة للوصول لباب المحل.
4. **سجل متابعة الزيارات:** تحديد حالة العميل (`لم تتم` / `تم البيع والتعاقد 🟢` / `يحتاج متابعة 🟡` / `غير مهتم 🔴`) وكتابة الملاحظات مع الحفظ التلقائي في ذاكرة الجهاز.
5. **تصدير إكسل بنقرة واحدة:** تنزيل ملف `khobar_packaging_leads.csv` المتوافق مع برامج Excel ومسؤولي المبيعات.
