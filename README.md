# 🚗 دليل كافيهات الخبر وضواحيها لمناديب المبيعات والزيارات الميدانية (مرتب بالمسافة)

ملف تفاعلي شامل مصمم خصيصاً **لفريق المبيعات والمناديب الميدانيين** لجدولة الزيارات اليومية وبيع المنتجات (حبوب البن، المواد الأولية، مستلزمات المقاهي، الأكواب، السيروبات، وأنظمة الكاشير) للمقاهي والمحامص في **مدينة الخبر والظهران وضواحيها**.

---

## 🌟 ميزات نظام المبيعات والمسافات الميدانية:
1. **الترتيب الذكي بالمسافة (Distance Sorting):**
   - **📍 زر الموقع الحي (GPS):** يحدد موقع المندوب الحالي على الخريطة ويقوم فوراً بحساب المسافة الدقيقة لكل كافيه ويرتبها من الأقرب إلى الأبعد.
   - **🗺️ نقاط الانطلاق الميدانية السريعة:** إمكانية اختيار نقطة بداية الجولة (مجمع المطل، الحزام الأخضر، باتيو سنتر، البندرية، الراكة، أو إثراء والظهران) لحساب المسافات مسبقاً وتفادي هدر الوقت في التنقل.
2. **7 مسارات جولات ميدانية متسلسلة جغرافياً (Route Zones):**
   - **مسار 1: الكورنيش وأجدان ومجمع المطل (10 كافيهات متقاربة)**
   - **مسار 2: الخبر الشمالية واليرموك (4 كافيهات)**
   - **مسار 3: البندرية والعقربية (4 كافيهات)**
   - **مسار 4: الحزام الأخضر والذهبي والعليا والبستان (8 كافيهات)**
   - **مسار 5: الراكة الجنوبية والصفا (2 كافيهات)**
   - **مسار 6: الظهران وإثراء والدوحة (3 كافيهات)**
   - **مسار 7: التحلية وجنوب الخبر (1 كافيه)**
3. **توجيه مباشر بالملاحة:** زر ملاحة GPS يفتح خرائط جوجل مباشرة ويوجه المندوب لباب الكافيه.
4. **نظام متابعة الزيارات وتسجيل الملاحظات:**
   - خيارات حالة الزيارة: (⚪ لم تتم / 🟢 تم البيع والتعاقد / 🟡 يحتاج متابعة / 🔴 غير مهتم).
   - كتابة ملاحظات المندوب (اسم مسؤول المشتريات، موعد المتابعة، والطلبات) وتُحفظ تلقائياً في المتصفح.
5. **تصدير إكسل بنقرة واحدة:** زر تصدير يُنشئ ملف Excel كامل ببيانات الزيارات الميدانية والملاحظات.

## 🚀 كيفية رفع الملف إلى مستودع GitHub وتفعيله كصفحة ويب (GitHub Pages):

### 1. أوامر Git للرفع إلى المستودع:
افتح موجه الأوامر (Terminal أو PowerShell) في مجلد المشروع ونفّذ الأوامر التالية:

```bash
git init
git add .
git commit -m "إضافة دليل كافيهات الخبر الميداني للمبيعات مرتب بالمسافة"
git branch -M main
git remote add origin https://github.com/اسم_حسابك/اسم_المستودع.git
git push -u origin main
```

### 2. تفعيل التصفح المباشر عبر الجوال والكمبيوتر (GitHub Pages):
1. ادخل على صفحة المستودع في **GitHub**.
2. اضغط على **Settings** (الإعدادات).
3. اختر من القائمة الجانبية **Pages**.
4. تحت قسم **Build and deployment**، اختر الفرع **main** والمجلد `/ (root)` ثم اضغط **Save**.
5. خلال ثوانٍ سيظهر لك رابط مباشر مثل:
   `https://username.github.io/cafe/`
   يمكنك إرساله لمناديب المبيعات لفتحه مباشرة من جوالاتهم في الميدان دون الحاجة لتحميل أي برنامج!
